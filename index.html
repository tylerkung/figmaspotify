Remote for Spotify

Control Spotify playback from inside Figma.

A small Figma plugin that gives designers a Spotify Connect remote — see what's playing, skip and pause, search the catalog, and switch devices, without leaving Figma.

View source on GitHub

How it works

  • Sign in once with your existing Spotify account
  • The plugin remote-controls whichever device you already have running — desktop app, phone, or open.spotify.com
  • Compact view collapses the player into a single 64px bar so it stays out of the way
  • No backend touches your data — auth tokens live only in Figma's local plugin storage

What it isn't

This plugin does not stream audio inside Figma — Figma's plugin sandbox doesn't permit it. It's a remote for the Spotify app you're already running. It is not affiliated with, endorsed by, or sponsored by Spotify AB.
